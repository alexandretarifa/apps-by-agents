# Todo List App

A simple, beautiful, and minimal Todo List application built with HTML, CSS, and JavaScript. Todos persist in your browser's localStorage.

## Features

- Add new todos
- Mark todos as complete/incomplete
- Delete todos
- Persistence via localStorage
- Responsive, modern design

## Usage

1. Clone or download the repository.
2. Open `todo-list-app/index.html` in your browser.
3. Start adding your tasks!
